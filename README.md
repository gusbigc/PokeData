# PokeData 

Site que busca dados de pokémons usando a PokeAPI, mostrando altura, peso, tipo, stats e imagem.
O meu intuito fazendo esse site é aprender um pouco sobre API e integração com front-end(bem básico).

## Tecnologias usadas
- Python
- Flask
- HTML/CSS

## Funcionalidades
- Busca de pokémon por nome
- Exibição de tipo, altura, peso e stats
- Em breve terá mais conteúdo, como: poder escolher a versão do jogo que você quer buscar o pokémon e lugares de encounters
